# Dynamic Live Cropper ✂️🔴

Esta extensión te permite seleccionar cualquier área de una pestaña web y crear un panel flotante (Picture-in-Picture) que refleja en vivo todo lo que sucede en ese recorte. Ideal para monitorear videos, chats, letras de canciones o gráficos en tiempo real.

## ⚙️ ¿Cómo instalar la extensión gratis?

Como esta extensión no está en la Chrome Web Store, puedes instalarla en modo desarrollador siguiendo estos 4 sencillos pasos:

1. Haz clic en el botón verde **"Code"** arriba en esta página y selecciona **"Download ZIP"**.
2. Descomprime el archivo `.zip` que acabas de descargar en una carpeta de tu computadora.
3. Abre Chrome (o cualquier navegador basado en Chromium como Edge/Brave) y escribe en la barra de direcciones: `{navegador}://extensions/`; o dirigite a la pestaña de extensiones de tu navegador.
4. Arriba a la derecha, activa el interruptor que dice **"Modo de desarrollador"**.
5. Aparecerán nuevos botones arriba a la izquierda. Haz clic en **"Cargar descomprimida"** (Load unpacked) y selecciona la carpeta que descomprimiste en el paso 2.

¡Listo! Ya puedes anclar la extensión en tu barra de extensiones y empezar a recortar la web.
